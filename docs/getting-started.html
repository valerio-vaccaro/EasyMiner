Quick start

From source to dashboard.

Build, flash, and configure any of the sixteen EasyMiner, BLOXMiner, OfficineBitcoinMiner, or SatoshiSpritzMiner targets.

1. Install PlatformIO

Use the PlatformIO CLI or the PlatformIO IDE extension for VS Code.

pio --version

2. Choose, build, and flash

Choose an environment from the supported variants matrix. For example:

# Standard EasyMiner
pio run -e esp32-headless -t upload

# BLOXMiner
pio run -e esp32-headless-blox -t upload

# OfficineBitcoinMiner
pio run -e esp32-headless-officinebitcoin -t upload

# SatoshiSpritzMiner
pio run -e esp32-headless-satoshispritz -t upload

# ESP32-S3 SatoshiSpritzMiner
pio run -e esp32s3-headless-satoshispritz -t upload

For multiple boards, specify the port with --upload-port /dev/ttyUSB0. PlatformIO embeds the selected brand logo during the build.

3. Configure Wi-Fi and mining

On first boot, join the access point matching the selected brand:

  • EasyMiner_XXXX
  • BLOXMiner_XXXX
  • OfficineBitcoinMiner_XXXX
  • SatoshiSpritzMiner_XXXX

Complete the captive portal with Wi-Fi, wallet, worker, and pool settings. The default pool is solo.homeminingitalia.org on port 3340, with password x. The default worker is the selected firmware brand.

Open http://easyminer.local/ from a device on the same network. If mDNS is unavailable, use the device IP shown in the serial log or router DHCP list. The dashboard uses HTTP port 80; live statistics use WebSocket port 81.

Keep wallet and pool credentials out of source control and issue reports. The repository link shown by every firmware variant remains https://github.com/valerio-vaccaro/EasyMiner.

Build outputs

PlatformIO places raw files in .pio/build/<environment>. The post-build script also prepares named update and factory images for CI packaging.

GitHub Actions also creates a diyflasher-easyminer artifact after all sixteen builds complete. It contains firmwares-easyminer.json and the factory/component images under assets/easyminer/, ready to be copied into a diyflasher checkout.
