Quick start

From source to dashboard.

Build with PlatformIO, flash your board, and configure it from the captive portal.

1. Install PlatformIO

Use the PlatformIO CLI or the PlatformIO IDE extension for VS Code.

pio --version

2. Build and flash

pio run -e esp32-headless
pio run -e esp32-headless -t upload

# ESP32-S3 DevKit
pio run -e esp32s3-headless -t upload

3. Configure Wi-Fi and mining

  1. On first boot, join the EasyMiner_XXXX Wi-Fi network.
  2. Complete the captive portal with your Wi-Fi, wallet, worker, and pool settings.
  3. Open the device IP in a browser. The dashboard is on HTTP port 80; live statistics use WebSocket port 81.
Keep wallet and pool credentials out of source control and issue reports.

Build outputs

PlatformIO places raw files in .pio/build/<environment>. The post-build script also prepares named update and factory images for CI packaging.
