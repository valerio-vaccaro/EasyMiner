Automation

Fresh binaries on every build.

The firmware workflow builds each supported environment independently and preserves its output as a downloadable GitHub Actions artifact.

Update image

*_firmware.bin contains the application image for an update workflow.

Factory image

*_factory.bin combines bootloader, partition table, and application at their flash offsets.

Raw components

Bootloader, partitions, and application files are retained for advanced flashing and debugging.

Download

Open the repository’s Actions tab, choose a successful Build firmware run, and download the artifact for your board environment.

Flash with esptool

esptool.py --chip esp32 write_flash 0x10000 esp32-headless_firmware.bin

Verify the chip family and flash offsets for your board before using a manual command.
