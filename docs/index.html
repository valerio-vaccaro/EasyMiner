Open-source ESP32 firmware

Mine. Learn. Build.

EasyMiner is a compact Bitcoin solo-mining firmware with hardware SHA-256, Stratum support, Wi-Fi provisioning, persistent settings, and a live web dashboard.

Build your first imageDownload firmware
⚡

Fast hashing

Uses ESP32 hardware SHA acceleration and dedicated FreeRTOS mining tasks where available.

🌐

Web configured

Connect to the EasyMiner access point, save Wi-Fi and pool settings, then watch the dashboard.

📦

Build artifacts

GitHub Actions creates named update images and merged factory images for supported boards.

⚠️ Solo mining has extremely small odds of finding a block. This project is for experimentation and education.
