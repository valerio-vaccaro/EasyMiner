Branding and defaults

Each branded image includes its logo in the firmware web interface and uses the matching default worker name. Existing custom worker names are preserved when changing firmware variants.

The repository link shown in every firmware page is always EasyMiner.

Board-specific settings

Pin assignments, LED behavior, CPU/task settings, network defaults, and compile-time profiles are defined in include/board_config.h. Update the PlatformIO environment and matching macro together when adding hardware.
