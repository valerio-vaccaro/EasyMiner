ℹ️ About %BRAND%

%BRAND% is a headless Bitcoin solo-mining firmware for ESP32 and ESP32-S3 boards. It connects to a Stratum pool, downloads work templates and searches for a valid Bitcoin block using the board SHA-256 hardware and optimized mining tasks.

The project is based on ideas and implementation patterns from SparkMiner and NerdMiner V2, adapted for a display-free web interface.

⚙️ Features

  • Wi-Fi configuration and persistent settings stored in NVS.
  • Mining on Core 0, Core 1, both cores, or disabled per core.
  • Live dashboard with WebSocket updates, hashrate, pool difficulty, shares, templates, blocks, temperature and memory charts.
  • Configuration, pool presets, reboot and factory-reset controls from the web interface.

🤝 Contributions

Contributions are welcome: report reproducible issues, improve documentation, test on additional ESP32 boards, optimize SHA-256 performance, or submit focused pull requests.

Please keep changes small and documented, avoid committing credentials, and include the target board and build output when reporting firmware problems.
